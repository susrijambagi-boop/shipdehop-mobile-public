# Flutter Native Setup

Run `flutter create . --platforms=android,ios` in this directory first. Then apply the following platform configuration.

## Google Maps

### Android
Add your Android Maps SDK key inside `<application>` in `android/app/src/main/AndroidManifest.xml`:

```xml
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_ANDROID_MAPS_KEY" />
```

Add foreground location permissions above `<application>`:

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
```

Only add background-location permissions if ShipdeHop later supports tracking while the app is backgrounded and your UX/policy disclosures meet platform requirements.

### iOS
Add location usage text to `ios/Runner/Info.plist`:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>ShipdeHop uses your location to match routes and show active trip tracking.</string>
```

Provide the iOS Maps SDK key from `AppDelegate.swift` using the native Google Maps SDK initialization required by `google_maps_flutter`.

## Parcel inspection image capture

For iOS, add:

```xml
<key>NSCameraUsageDescription</key>
<string>ShipdeHop uses the camera to inspect parcels and detect unsafe items.</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>ShipdeHop lets you choose parcel photos for HopShield inspection.</string>
```

Android camera/media permissions should follow the Android SDK level generated by your installed Flutter/plugin versions; do not add broad storage permissions unnecessarily.

## Stripe

Use only `STRIPE_PUBLISHABLE_KEY` in Flutter. The Stripe secret key remains in `backend/.env`. Follow the installed `flutter_stripe` package's Android min-SDK/MainActivity and iOS deployment-target requirements after `flutter pub get` so the native setup matches the exact resolved plugin version.

## Razorpay

Use only `RAZORPAY_KEY_ID` in Flutter. `RAZORPAY_KEY_SECRET` remains server-side. The server creates the Razorpay Order and returns the exact provider minor-unit amount used by Checkout; the mobile app does not recalculate currency minor units.

## Supabase

Flutter gets only:

- `SUPABASE_URL`
- `SUPABASE_PUBLISHABLE_KEY`

Never place `SUPABASE_SERVICE_ROLE_KEY` in Dart defines, assets, plist files, Android resources, or the compiled application.
