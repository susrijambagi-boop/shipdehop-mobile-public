Frequently Asked Questions

  • How does HopShip parcel delivery work? Senders list parcel details and complete a HopShield AI package inspection. Travellers on matching corridors reserve and carry the parcel to the destination. Physical handoff is verified using secure OTP/QR codes.
  • How does HopRide work? Drivers publish available corridor seats. Passengers match with drivers traveling along the same route for safe, affordable cost-sharing mobility.
  • What is HopShield inspection? HopShield is our AI-assisted visual inspection system that screens package photos to detect prohibited, dangerous, or illegal items before matching.
  • How do I request account deletion? You can delete your account inside the mobile app via Settings → Delete account & data or by visiting our Account Deletion Request Page.
